# Time Value Counter

**Presence-verified counting to 100,000.**

Inspired by MrBeast’s legendary “counting to 100,000” video — but designed for people who have jobs, students, and lives. You don’t need a camera, a studio, or 40 straight hours. You just need focused attention, one number at a time.

This app exists to make one simple point tangible:

> Most people will never count this high.  
> Yet the money supply keeps expanding.  
> What is your time actually worth?

## Features

- **Every count is timestamped** and saved locally
- **Session notes** — record what was happening in the background (kids, meetings, deep work, traffic…)
- **Presence awareness** — counting pauses / warns when the tab loses focus
- **Live stats**: active time, sessions, average rate, estimated finish date
- **Full exportable proof log** (JSON) so you can keep a permanent record of the time you spent
- Works offline, zero accounts required, data stays on your device
- Keyboard support: press **Space** to count
- Clean, focused dark UI

## How to use

1. Open `index.html` (or visit the GitHub Pages link once published)
2. Enter a name / alias
3. Start counting. Stay on the tab. Add notes whenever something is going on around you.
4. Export your log regularly — it’s your proof of time.

## Philosophy

The original MrBeast video was entertainment and endurance.  
This version is quieter and more personal:

- It forces you to confront how long 100,000 focused moments actually take.
- It creates an immutable personal log of attention.
- It sits next to the daily reality that currencies inflate while most humans have never even counted that high.

You can treat it as a meditation, a productivity experiment, a statement, or just a long game with yourself.

## Tech

Pure client-side HTML + CSS + vanilla JS.  
No build step, no backend, no tracking.  
Data lives in `localStorage`. Export often.
